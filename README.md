# Aurevia Motors - Premium Automotive Landing Page

## Business Concept
Aurevia Motors is a luxury car showroom and agency landing page designed to showcase premium vehicles, compare specifications, and book test drives.

## Features
- Sticky navigation with smooth scrolling
- Hero section with primary CTAs
- Car collection cards with hover effects
- Smart Garage tools (Compare Cars, Favourites, EMI Calculator)
- Ownership pricing plans
- Testimonial slider and interactive FAQ accordion
- Contact form with embedded Google Map

## Tech Stack
- HTML5, CSS3, JavaScript, Bootstrap 5
